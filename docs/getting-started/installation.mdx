<div slot="installer">

```sh
curl -fsSL https://raw.githubusercontent.com/casoon/auditmysite/main/install.sh | bash
```

macOS and Linux. The script downloads the latest GitHub release for your platform and checks it
against the published `.sha256` file before installing. Run it again to upgrade: it replaces the
binary where it already lives.

</div>
<div slot="cargo">

```sh
cargo install auditmysite
```

Builds from source on crates.io. The PDF report (feature `pdf`) is on by default.

</div>
<div slot="binary">

Each [GitHub release](https://github.com/casoon/auditmysite/releases) carries one archive per
target, each with a `.sha256` checksum:

| Target | Archive |
| --- | --- |
| macOS, Apple silicon | `auditmysite-vX.Y.Z-aarch64-apple-darwin.tar.gz` |
| Linux x86_64 | `auditmysite-vX.Y.Z-x86_64-unknown-linux-gnu.tar.gz` |
| Linux arm64 | `auditmysite-vX.Y.Z-aarch64-unknown-linux-gnu.tar.gz` |
| Windows x86_64 | `auditmysite-vX.Y.Z-x86_64-pc-windows-msvc.zip` |

</div>
<div slot="source">

```sh
git clone https://github.com/casoon/auditmysite.git
cd auditmysite
cargo build --release
./target/release/auditmysite --version
```

`rust-toolchain.toml` pins the Rust version; rustup picks it up inside the repository. There is
no MSRV promise, older compilers are not supported.

</div>
</Tabs>

<Callout type="caution">
  If you installed with `cargo install` before, remove `~/.cargo/bin/auditmysite` before using the
  installer script, so only one binary is on your `PATH`.
</Callout>

## Optional Cargo features

| Feature | Adds | Default |
| --- | --- | --- |
| `pdf` | PDF reports via the renderreport/Typst engine | on |
| `ai-transparency` | C2PA image-provenance check, runtime flag `--ai-transparency`, single URL only | off |

## A browser

auditmysite does not download a browser on its own. It uses an installed Chrome or Chromium, or
one you install explicitly with `auditmysite browser install`. See
[Browser setup](../../guides/browser-setup/).

## Verify the install

```sh
auditmysite --version
auditmysite doctor
```

`doctor` checks the browser, permissions and connectivity. Continue with the
[Quickstart](../quickstart/).
